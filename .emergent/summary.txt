<product_requirements>
The initial product aimed to build an employee work management system where employees log in to access work and deadlines. They upload completed work, which is visible in an admin portal. The admin can also track employee daily work time. The system evolved into "Life Lines Work Portal, adding:
- Admin download of uploaded work.
- Amount calculation per work, credited upon admin acceptance; rejection triggers resubmission with comments.
- Employee dashboard displaying credited amounts.
- Admin portal showing all amounts and payment done option.
- Portal on/off switch.
The system then transformed into a 5-level MLM portal:
- Members join 5 friends, assigned work, and paid for each.
- Admin controls work and amount.
- Member dashboard displays credited, debited, and balance, with daily work visibility.
- Daily work amounts accumulate.
- Minimum withdrawal of ₹100, eligible after 5 joinees.
- Request withdrawal option for members, processed by admin.
- Login using mobile number (OTP skipped, used as username).
- Registration fee with 10 installment payments.
- Human tree network visualization for members and admin.
- Admin configurable commission percentages (Level 1: 5%, Level 2: 3%, Levels 3-5: 1%).
- Employee dashboard to show Your Contribution instead of Account Balance.
- Admin can assign tasks to specific employees or all employees at once.
- Admin visibility of joinees under every member.
- Daily work report submission with specific columns (class, subject, details) for employees, downloadable in Excel format for admin.
- Enhanced file type support (image, pdf, video, ppt, excel, collage) for task upload/submission.
</product_requirements>
